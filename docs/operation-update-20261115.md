# 問題点

## 【重大】

- 3795とトヨクモの組み合わせは不一致。公式コードは4058だが、元の選定根拠の帰属を未確認のまま自動置換しない。該当1件だけ保留。
- 2180サニーサイドアップグループは2026-09-16に上場廃止。原リストの履歴は保持し、新規候補から除外。
- 未調査105社の財務数値を推定で埋めていない。通期合格以外の109社は財務ゲートで確認・審査待ち。この数はTOPIX・流動性等で既に除外された銘柄も含む。

## 【中程度】

- 日本マイクロニクス・ほぼ日の公式動的IR feedは取得不能。11/15はTDnet配信一覧を手動確認しているが、翌営業日以降の自動鮮度確認は未登録。
- TOPIX登録の再確認期限は11/29。次の公表済み組入れイベント11/30に向けた運用期限であり、期限の自動延長はしない。
- 日次一覧チェックは非財務ニュースでも保留になる場合があり、同URL・同タイトルのPDF無告知差替えを完全検知するものではない。
- 最新日足の価格判定待ちは5件（2180、3359、3795、5367、6518）。不正な値や古い日付は採用していない。

## 【軽微】

- 3695の表示社名をGMOプロダクトプラットフォームに修正。元の受領名称は保存。
- Scriptable端末内のJSはGitHubのJSを更新するだけでは自動的に差し替わらない。v7も更新された候補配列を利用可能。受入件数の追加表示にはv8を利用する。

# 統計監査

今回の112は監視母集団数であり、取引サンプル数ではない。新規売買バックテストは実施しておらず、勝率・期待値・PF・最大ドローダウン・シャープレシオ・統計的有意性はいずれも未算定。従来のPF4.11を今回のロジックの性能とはみなさない。

先読みを避けるため受入日・公表日・確認日・価格日を分離した。ただし公表時刻を網羅しておらず、場中取引のバックテストに転用しない。生存者バイアス、過剰最適化、相場環境依存性、ウォークフォワードの適切性は、過去のその時点の母集団と約定ルールを使う検証が必要。

# コード監査

新しい取得処理を財務評価と分離し、取得失敗・空HTML・資料不在・未来情報・根拠変更で確認済みにしないことを検証した。JSONは全体の妥当性を確認してから置き換え、失敗時に前回データを壊さない。

実行時に株価配信の取得制限を確認。取得制限はAPIが返した事実としてログに残す。同日キャッシュは有効な価格観測に限定して再利用する。保有銘柄の未検証raw日足を同日キャッシュの成功と混同する既存不具合は、今回の実行検証で発見して修正した。未検証・古いraw日足から保有損益を計算せず、同日キャッシュが有効でも保有欄だけ確認待ちにする。

Python 87件とScriptableのアプリ／ウィジェット表示テストがローカルで合格。IR一覧5社の実取得もすべて差分なし、TOPIX公式ニュースの再取得も成功。GitHub Actionsの本番実行は公開反映の承認待ち。ローカルでは同じ実行順序で成功を確認した。テスト合格は収益性の証明ではない。
